## 🌟 特色亮點 (Features)

- 🌸 **品牌首頁 (Home Tab)**：融入香港紫荆花交互动效、九声六调色彩拆解、沉浸式浮窗演示与三大生态支柱。
- 🧭 **學習導航 (Roadmap Tab)**：权威精选 27+ 顶尖粤语学习资源（发音教程、在线辞书、输入法、泛读材料、播客影视），支持多维度即时搜索与分类筛选。
- 🧩 **懸浮擴展 (Extension Tab)**：粤语悬浮词典 Chrome 扩展官方功能展示、下载入口与使用指南。
- 🌓 **深色/淺色自適應**：全站支持暗黑模式与流畅微动效。
- 💬 **意見反饋與資源推薦**：集成用户反馈与资源提交通道。

## 🛠️ 技術棧 (Tech Stack)

- **Framework**: [Next.js 16 (App Router)](https://nextjs.org/) + [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animation**: [Framer Motion](https://www.framer.com/motion/)
- **Icons**: [Lucide React](https://lucide.dev/) + [Simple Icons](https://simpleicons.org/)
- **Deployment**: [Vercel](https://vercel.com/)

## 🚀 本地開發 (Local Development)

```bash
# 1. 安装依赖
npm install

# 2. 启动开发服务器
npm run dev

# 3. 生产构建
npm run build
```

访问 [http://localhost:3000](http://localhost:3000) 即可在本地预览。
